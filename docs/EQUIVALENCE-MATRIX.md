# Equivalence matrix: legacy HAAS behaviour → `x_cog_mah` implementation → proving test

Each row names a behaviour of the legacy Domino application (validation, computed item, agent, view,
ACL role, form, XPage or export), the file(s) in this repository that implement the equivalent, the
instance artefact(s) the Fluent build creates, and the Vitest case (by exact title) that proves it.
Rows with no test are pure metadata and are verified by `now-sdk build` plus the on-instance screenshots
in `docs/SCREENS.md`.

The matrix body is generated from `tools/lib/docs-catalog.ts` by `npm run gen:docs`;
`tests/docs-sync.test.ts` fails if a referenced file or test title no longer exists, or if a test file
gains a case that no row references.
